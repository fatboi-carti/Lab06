# Итоговый вопрос
Процессор не запускает программу из постоянной памяти. Программа загружается в оперативную(временную) память для большей эффективности, а оттуда уже что-то идёт даже в память процессора. Поэтому нельзя сказать, что программа запускается прямо с HDD/SDD.
Операционная система распределяет ресурсы компьютера и регулирует запуск программ.

# Контрольные вопросы
1. Файл программы на HDD/SSD это как список того, что нужно выполнить. А уже запущенная программа это результаты дел этого списка.
2. В оперативной памяти программа хранит все самые нужные для её работы данные, чтобы ОПЕРАТИВНО к ним обратиться в любой момент.
3. В Диспетчере задач можно найти сам процесс программы, ну или заметить нагрузку на ЦП.
4. В нашей программе вычисляются очень большие числа, это и нагружает процессор так сильно.
5. После завершения программы её файл с HDD/SSD никуда не пропадает.

# Итоговый вывод
Программа хранится как файл на компьютере, что-то типа набора инструкций, которые предстоит выполнить. Далее эти инструкции поступают в оперативную память, чтобы можно было быстрее к ним обращаться. Создаётся процесс нашей программы, который и выполняется на CPU. Во время выполнения также может задействоваться дополнительная оперативная память для хранения данных при выполнении программы. После завершения процесса всё очищается, а файл программы остаётся.
